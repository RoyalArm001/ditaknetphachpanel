# Կատարված թեստերի գրանցամատյան

Թարմացված է՝ 2026-10-16։ Վերջին ստուգված գործառութային թարմացումը՝ 2.11.14։ Այս գրանցամատյանն ու բրենդի պլանն ավելացվել են 2.11.12 փաստաթղթային թարմացմամբ։

Այս ֆայլը պահում է ստուգումների ամփոփումը՝ ժամանակավոր լոգերն ու նկարները մաքրելուց հետո։ Արդյունքները վերցված են տեղային լոգերից և այս աշխատանքային նիստում կատարված ստուգումներից։ Ֆայլերի հեղինակին՝ Codex կամ Gemini, միայն անուններով հուսալիորեն որոշել հնարավոր չէ։

## Ավտոմատ թեստեր

### Քարտեզի PDF և սարքերի սխեմաներ — 2026-10-16, v2.11.14

- Ամբողջական suite՝ **130/130 հաջող**։ Նոր թեստերը ստուգում են A3 քարտեզի և A4 սարքերի էջերի համատեղ արտահանումը, տեքստերի սահմանները, էջատակերը և հարկերի/տարածքների հերթականությունը։
- 72 սարքով քարտեզը ավտոմատ ստացել է մեկ A3 էջ՝ բոլոր 72 անուններով։
- Սարքերը դասավորվում են ըստ U դիրքի՝ վերևից ներքև։ Պորտերի անուններն ու համարները պահպանված են նոր տեսքում։
- Բրաուզերում ներբեռնված A3 PDF-ի իրական էջաչափը ստուգված է։ Հակիրճ և մանրամասն նախադիտումները աշխատում են։
- Demo-ի հակիրճ PDF-ը՝ 4 էջ, բոլոր էջերը արտապատկերվել են PNG-ների՝ տեսողական ստուգման համար։
- `npm run check` և `npm run build`՝ հաջող։

### Սարքերի ընտրության թարմացում — 2026-10-16, v2.11.13

- `npm test`՝ **127/127 հաջող**։ Նոր թեստերը ստուգում են արտադրողի, պորտերի ճշգրիտ քանակի և PoE-ի համակցված ֆիլտրերը և Grandstream-ի 8 հաստատված մոդելների տվյալները։
- `npm run check`՝ հաջող։
- `npm run build`՝ հաջող։
- Բրաուզերում ստուգվել են արտադրողի փոխարկումը, 12/24/48 պորտերի ընտրությունը, PoE/առանց PoE տարբերակները, ավտոմատ լրացումը, ձեռքով փոփոխությունների պահպանումը և սարքի իրական ավելացումը demo ռաքում։
- 390px և 1440px՝ բաց և մուգ թեմաներով, չմշակված JS սխալներ՝ 0։
- Grandstream-ի աղբյուր՝ [արտադրողի տեխնիկական տվյալներ](https://documentation.grandstream.com/knowledge-base/gwn780x-series-technical-specifications/)։ GWN7808P-ի ենթադրված բնութագրեր չեն ավելացվել։

### Նախորդ գործարկումներ

- Վերջին ամբողջական գործարկում՝ **125 թեստ, 125 հաջող, 0 սխալ, 0 բաց թողնված**։ Աղբյուր՝ `test-output/vlan-tests.log`, մինչև մաքրումը։
- `npm run check`՝ հաջող, ներառյալ VLAN-ի տեղափոխման թարմացումը։
- `npm run build`՝ հաջող, ներառյալ VLAN-ի տեղափոխման թարմացումը։
- Նախորդ պահպանված արդյունքները՝ 100 թեստ՝ օգնություն և քարտեզի չափեր, 104՝ քարտեզի պիտակներ և հեղինակ, 117՝ PIN-ի հիշողություն, 123՝ PDF, 125՝ պորտերի ընտրություն։ Սրանք տարբեր ժամանակների գործարկումներ են, դրանց քանակները չեն գումարվում։

### Ինչ են ծածկում պահպանված թեստերը

- Սարքերի մոդելներ, պորտերի քանակ, կրկնվող անուններ, ռաքերի կապեր և սարքերի ստեղծում։
- Պորտերի ընտրություն, կապի երկու ծայրերի ընդգծում և խմբային նշանակության կիրառում՝ նաև ռաուտերի վրա։
- Քարտեզի պիտակների դասավորություն, սարքերի խմբեր, PDF ընտրության սահմաններ և նախադիտման նույնական ներբեռնում։
- Հակիրճ PDF-ի էջերի քանակ, համարների դիրք, մալուխների անուններ, մեծ պանելների էջավորում և գաղտնի տվյալների բացառում։
- PIN-ի պահպանում, սեսիաներ, դուրս գալ, audit log և տվյալների թարմացում։
- Backup retention, մեկուսացում և deployment runner-ի տեղային ստուգումներ։
- Օգնություն, demo, նախագծերի տեղափոխում և ավտոմատ գիշերային ռեժիմ։

Թեստերի սկզբնական կոդը պահպանված է [tests](../tests/) պանակում։

## Բրաուզերում կատարված ստուգումներ

### VLAN և պորտերի ընտրություն — 2026-10-16

- Ցանկից VLAN ընտրել, ձեռքով `377` գրել, պահպանել և մաքրել։
- «Այլ տվյալներ» բաժնում սկզբում փակ VLAN դաշտը բացել և խմբագրել։
- Ctrl-ով ընտրելուց առաջ ընթացիկ սևագրի պահպանում։
- Անվանակարգ չունեցող պորտի և կապի երկու ծայրերի տեսանելի ընդգծում։
- Ընտրվածների ցանկում պորտերի, ռաքի և նշանակության ցուցադրում։
- Սեփական նշանակության կիրառում ընտրված պանելի և ռաուտերի պորտերին՝ չընտրվածները պահպանելով։
- Desktop և 390px mobile տեսքի դիտարկում, բրաուզերի չմշակված JS սխալներ՝ 0։

### PDF և PIN պատուհան

- Demo նախագծի ամբողջական հակիրճ PDF՝ **4 էջ**, միայն քարտեզը՝ **1 էջ**։ Սա demo-ի արդյունքն է, ոչ բոլոր իրական նախագծերի հաստատուն էջաքանակը։
- PDF-ի բոլոր 4 էջերը վերածվել են նկարների և տեսողական ստուգվել։
- Նախադիտման հակիրճ և մանրամասն ձևաչափերի փոխարկումը ստուգվել է բրաուզերում։
- PIN պատուհանի checkbox/տեքստ դասավորությունը ստուգվել է 390px և 1440px չափերով՝ բաց և մուգ թեմաներում։
- PIN-ի հիշողության նախկին ստուգումը ներառել է էջի թարմացումներ, բրաուզերի ու սերվերի վերագործարկում, ժամանակավոր DB խափանում և կրկնափորձ։

Պահպանված ցուցադրական արդյունքը՝ [MyPatch-compact-demo.pdf](../output/pdf/MyPatch-compact-demo.pdf)։ Ֆայլը տեղային է և Git-ում չի հրապարակվում։

### Նախկին P2 ստուգման պահպանված ապացույց — 2026-10-12

`test-output/p2-qa/results.json`-ում գրանցված էր՝

- 72 դասավորության ստուգում՝ քարտեզի և որոնման էջերի համար։
- Լայնություններ՝ 390, 430, 768, 1024, 1440, 1920px։
- Լեզուներ՝ HY, EN, RU։ Թեմաներ՝ բաց և մուգ։
- Գրանցված layout ստուգումներում հորիզոնական արտահոսք կամ կտրված տարրեր չեն հայտնաբերվել։
- Սկզբնական քարտեզում՝ 55 նշիչ։

Այս արդյունքը չի հաստատում 100/200 սարքերի performance-ը, իրական touch սարքի աշխատանքը կամ ամբողջ հավելվածի A11y համապատասխանությունը։ Դրանք առանձին ստուգումներ են։

## Դեռ չհաստատված

- Իրական Supabase Cloud-ում backup-ի ստեղծման, cron-ի, advisory lock-ի և shared/account E2E ստուգման հաջող արդյունք այս գրանցամատյանում չկա։ Տես [BACKUP-VERIFICATION.md](BACKUP-VERIFICATION.md)։
- Իրական հեռախոսի touch/pinch և ամբողջական keyboard/A11y ստուգումները պետք է ունենան առանձին գրանցում։
- 100 և 200 սարքերով քարտեզի ամբողջական performance չափումը այստեղ հաստատված չէ։
- Windows հավելվածի ամբողջական տեղադրման/հեռացման թեստ այս թարմացման շրջանակում չի կատարվել։

## Ինչպես կրկնել

Նախագծի հիմնական պանակում՝

```powershell
npm test
npm run check
npm run build
```

Բրաուզերի փորձերի համար օգտագործել `/?demo=1`՝ իրական նախագծերից անկախ։ Հաջորդ ստուգման ժամանակ ավելացնել ամսաթիվը, commit-ը, միջավայրը, արդյունքը և հայտնի սահմանափակումները։ Մի գրանցել PIN, cookie կամ միացման գաղտնիքներ։

## Տեղային մաքրում — 2026-10-16

- **Վիճակ՝ չի կատարվել։** Ջնջման երկու փորձն էլ գործիքների ավտոմատ անվտանգության ստուգումը մերժել է՝ `blocked by policy` պատասխանով։ Ստորև նշված ֆայլերը դեռ տեղում են։
- Մաքրման թիրախներ՝ `test-output/` և `native-windows/obj/`։ Դրանք Git-ում չպահվող փորձնական արդյունքներ և build-ի միջանկյալ ֆայլեր են։
- Մաքրումից առաջ՝ ընդհանուր 889 ֆայլ, մոտ 108.94 MiB։
- Պահպանվում են `tests/`, ծրագրի կոդը, տվյալները, backup-ները, կախվածությունները, պատրաստ build-երը և վերջնական PDF օրինակը։
- Օգտատիրոջ հիմնական բրաուզերի և համակարգային Codex/Gemini պանակների քեշերը չեն նույնացվել որպես այս նախագծի ժամանակավոր արդյունք։

Ձեռքով մաքրելու համար փակել թեստային բրաուզերներն ու ընթացիկ build-ը և File Explorer-ում միայն վերոնշյալ երկու պանակները տեղափոխել Recycle Bin։ Դրանք կարելի է վերաստեղծել հաջորդ թեստի կամ Windows build-ի ժամանակ։
