# Բրենդի պլան — նոր գաղափարի համար

Ամսաթիվ՝ 2026-10-16։ Վիճակ՝ **նախնական պլան, իրականացումը դեռ չի սկսվել**։

Նոր գաղափարի նկարագրությունը դեռ սպասվում է։ Մինչ այդ այս պլանի աշխատանքային հիմքը «My Patch» նախագիծն է։ Անունը, լսարանը և ստորև առաջարկվող ուղղությունը վերջնական որոշումներ չեն։

## 1. Նախ հստակեցնել գաղափարը

- [ ] Մեկ նախադասությամբ գրել՝ ինչ ենք ստեղծում և ինչ խնդիր է լուծում։
- [ ] Նշել հիմնական օգտատիրոջը և նրա ամենօրյա գործողությունը։
- [ ] Որոշել՝ սա My Patch-ի նոր հնարավորություն է, առանձին արտադրանք, թե մի քանի արտադրանքի ընդհանուր բրենդ։
- [ ] Գրել առաջին տարբերակի երեք հիմնական գործառույթը։
- [ ] Սահմանել՝ ինչ արդյունքից կհասկանանք, որ գաղափարը օգտակար է։

**Արդյունք՝** մեկ էջանոց գաղափարի նկարագրություն։ Սա առաջին առաջնահերթությունն է։

## 2. Բրենդի հիմնական խոստումը

Եթե ուղղությունը մնում է ցանցային ենթակառուցվածքի կառավարումը, աշխատանքային առաջարկն է՝

> Տեսնել ցանցը, արագ գտնել սարքը և հասկանալ՝ ինչն ինչին է միացված։

- [ ] Հաստատել հիմնական լսարանը՝ տեղադրող մասնագետ, ներքին IT թիմ կամ այլ օգտատեր։
- [ ] Ընտրել մեկ հիմնական առավելություն, որը կարող ենք ցուցադրել իրական demo-ով։
- [ ] Նկարագրել արտադրանքը երեք պարզ նախադասությամբ՝ առանց չստուգված խոստումների։
- [ ] Որոշել My Patch, Ditaknet և հեղինակի անունների դերը՝ արտադրանք, ընկերություն, հեղինակ։

**Արդյունք՝** հաստատված կարճ նկարագրություն և բրենդների կապի հստակ որոշում։

## 3. Անուն և խոսելու ոճ

- [ ] Պատրաստել 3–5 անվան տարբերակ՝ նոր գաղափարը ստանալուց հետո։
- [ ] Ստուգել հայերեն, անգլերեն և ռուսերեն արտասանությունն ու գրությունը։
- [ ] Ընտրված անունների համար ստուգել դոմեններն ու հանրային անվանումների համընկնումները։ Դեռ ստուգված չեն։
- [ ] Գրել կարճ կարգախոս և մեկ պարբերությամբ ներկայացում։
- [ ] Պահել պարզ, հանգիստ և մասնագիտական լեզու՝ կարճ կոճակներով ու հասկանալի սխալներով։

**Արդյունք՝** անուն, կարգախոս և HY/EN/RU ներկայացման տեքստեր։

## 4. Տեսողական համակարգ

- [ ] Պատրաստել լոգոյի 2–3 ուղղություն և փոքր չափով կիրառվող նշան։
- [ ] Ընտրել հիմնական գույն, լրացուցիչ գույներ և լուսավոր/մուգ թեմաներ։
- [ ] Տարանջատել բրենդի գույները սարքերի կարգավիճակի ու VLAN/նշանակության գույներից։
- [ ] Հաստատել հայերենը լավ ցուցադրող տառատեսակ և ընթեռնելի չափեր։
- [ ] Միատեսակ դարձնել կոճակները, դաշտերը, քարտերը և SVG նշանները։
- [ ] Պատրաստել PDF շապիկի, հաշվետվության էջատակի և հավելվածի նշանի ձևերը։

**Արդյունք՝** կարճ բրենդային ուղեցույց և կիրառելի SVG/գունային/տառատեսակային նյութեր։

## 5. Բրենդը կիրառել արտադրանքի մեջ

- [ ] Սկսել մուտքի էջից, demo-ից և գլխավոր մենյուից։
- [ ] Համադրել քարտեզի, ռաքի, որոնման և կարգավորումների տեսքը։
- [ ] Ընդլայնված դաշտերը պահել բացվող բաժիններում՝ հիմնական գործողությունները տեսանելի թողնելով։
- [ ] Համադրել օգնության, հեղինակի էջի և PDF-ի անվանումներն ու ձևավորումը։
- [ ] Նոր դիզայնը ստուգել HY/EN/RU լեզուներով, բաց/մուգ թեմաներում և տարբեր էկրանների վրա։

**Արդյունք՝** մեկ ամբողջական օգտատիրոջ ճանապարհ՝ մուտքից մինչև պահպանված կամ արտահանված արդյունք։

## 6. Փորձարկում և ներկայացում

- [ ] 3–5 նախատեսված օգտատիրոջ տալ հիմնական առաջադրանք՝ առանց նախապես բացատրելու քայլերը։
- [ ] Գրանցել՝ որտեղ են կանգ առնում, ինչ չեն գտնում և ինչ անվանում չեն հասկանում։
- [ ] Ուղղել կրկնվող խնդիրները և կրկնել ստուգումը։
- [ ] Պատրաստել կարճ demo, հիմնական պատկերներ և ներկայացման մեկ էջ։
- [ ] Թողարկումից առաջ ստուգել անունները, հղումները, PDF-ը, թարգմանությունները և տեխնիկական թեստերը։

**Արդյունք՝** ստուգված ներկայացում և թողարկման հստակ ցանկ։

## Հաջորդ քայլ

Լրացնել նոր գաղափարի նկարագրությունը, լսարանը և հնարավոր անունը։ Դրանց հիման վրա վերաշարադրել առաջին երեք բաժինները։ Մինչ այդ վերանվանում, նոր լոգո կամ ծրագրային փոփոխություններ այս պլանով չեն սկսվում։
