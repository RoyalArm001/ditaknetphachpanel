# My Patch Native — Windows 0.1.0

Սա առանձին Windows ծրագիր է՝ WPF պատուհաններով և SQLite բազայով։
Ծրագրում չկա Electron, Chromium, WebView կամ տեղային վեբ սերվեր։
Տեղային աշխատանքը չի պահանջում ինտերնետ կամ cloud մուտք։

## Տեղադրում և տվյալներ

- Windows 10 (2004 կամ նոր) / Windows 11, x64։ .NET-ը ներառված է։
- `MyPatch-Native-Setup-0.1.0-x64.exe`՝ տեղադրում ընթացիկ օգտատիրոջ համար։
- `app/MyPatch.Native.exe`՝ գործարկում առանց տեղադրիչի։
- Բազան՝ `%LOCALAPPDATA%\MyPatchNative\projects.sqlite`։
- Cloud session-ը պահվում է Windows DPAPI-ով պաշտպանված ֆայլում։
- Ծրագիրը հեռացնելը կամ նոր տարբերակը տեղադրելը չի ջնջում նախագծերի բազան։
- Կայքի JSON/XLSX պահուստային ֆայլը ներմուծվում է որպես նոր տեղային պատճեն։
- Նախկին Electron տարբերակի բազան ինքնաբերաբար չի տեղափոխվում․ օգտագործեք պահուստային ֆայլ կամ cloud մուտքը։
- Տեղադրիչը դեռ չունի հրատարակչի թվային ստորագրություն։

## Գործիքներ

- Նախագծեր, հարկեր, ռաքեր, սարքեր, պորտեր և դրանց կապեր։
- Սվիչների / ռաուտերների երկու շարքով պորտեր և առանձին SFP պորտեր։
- VLAN, IP հասցեներ, սարքերի նշանակություններ, անվանումներ և գույներ։
- Քարտեզի ներմուծում PDF-ից կամ նկարից, սարքերի տեղադրում / տեղափոխում / հեռացում։
- Տեղադրված սարքը թաքցվում է քարտեզի ընտրացանկից։
- Քարտեզների և սարքերի սխեմաների PDF պահպանում՝ հարկի, սարքի և լեզվի ընտրությամբ։
- Հաշվետվություն, CSV, JSON և XLSX պահուստային արտահանում։
- Undo / Redo և SQLite-ում պահվող նախկին տարբերակների վերականգնում։
- Ընտրովի cloud մուտք, համաժամացում, LIVE ցանկ, PIN կառավարում և միայն դիտելու հղումներ։
- Cloud փոփոխությունների բախման դեպքում տեղային տարբերակը պահպանվում է, իսկ ձեռքով համաժամացման հրամանը առաջարկում է պահել այն առանձին նախագծում և բեռնել cloud-ը։

## Առաջին native թողարկման սահմանները

Սա առաջին native թողարկումն է, և կայքի հետ ամբողջական ֆունկցիոնալ հավասարություն դեռ հաստատված չէ։
Cloud մուտքը, բազմաթիվ իրական օգտատերերով համաժամացումը և PIN կառավարումը այս հավաքման ընթացքում իրական հաշիվներով չեն ստուգվել։
Դրանք օգտագործում են գործող կայքի API-ն և պահանջում են ինտերնետ։
Սեփական DWG խմբագրիչ չկա․ հատակագծերը ներմուծվում են PDF/նկար ձևաչափով։
Native PDF էջերը 192 dpi պատկերներ են՝ հայերեն տառատեսակների տեսքը պահպանելու համար, տեքստը PDF-ում ընտրելի չէ։
Անգլերեն և ռուսերեն միջերեսները կիրառում են կայքի թարգմանությունները․ նոր native դաշտերի մի մասը դեռ հայերեն է։
Native ավտոմատ թարմացնող դեռ չկա։ Հաջորդ հավաքումը տեղադրվում է նույն թղթապանակում՝ բազան պահպանելով։
Կայքի հատվածային թարմացման համակարգը շարունակում է գործել առանձին։

## Build

```powershell
dotnet publish native-windows/MyPatch.Native.csproj -c Release -r win-x64 --self-contained true -o Native-Windows-Release/app
makensis native-windows/installer.nsi
```

`.NET 10 SDK` և NSIS են պահանջվում միայն հավաքող համակարգչում։
`Jint`-ը կառավարելի .NET գրադարան է՝ ընդհանուր վավերացման և merge կանոնների համար, ոչ բրաուզեր։
Նախագծի տվյալները չեն ուղարկվում կայք մինչև cloud մուտքը և համապատասխան հրամանը։

## Verification

Build + native offscreen rendering with synthetic projects: overview, map palette/markers, reports;

Production projects were not modified to verify this build.
