# PDF ստուգման օրինակներ

Այս օրինակները պահվել են ամբողջական հրապարակման օգտատիրոջ խնդրանքով։
Դրանք փորձնական գծագրեր են և հավելվածի հրապարակային ֆայլերի ցանկում չեն ներառվում։

- `drawing-import-two-pages.pdf` — երկու էջի ներմուծման և հարկերին կցելու փորձ։
- `adaptive-labels-preview.*` — խիտ դասավորված նշանների անվանումների չափերի օրինակ։
- `label-tips-preview.*` — անվանումից դեպի սարքը ուղղված նշիչների օրինակ։
- `specialist-true.*` / `specialist-false.*` — ՏՏ մասնագետի ստորագրությունը միացված և անջատված արտահանում։

PNG-ները համապատասխան PDF-ների տեսողական ստուգման պատկերներն են։
